# AirPlay Receiver для Android TV

Приложение для Android TV, позволяющее транслировать видео с iPhone, iPad и Mac через протокол AirPlay. Работает как фоновая служба — после запуска приложение остаётся активным и принимает подключения, даже если вы переключились на другое приложение.

## Возможности

- Приём видео через AirPlay с устройств Apple
- Работа в фоновом режиме (foreground service)
- Автозапуск при включении ТВ-приставки
- Поддержка управления воспроизведением (пауза, перемотка, стоп) с устройства-отправителя
- Поддержка HLS и DASH потоков
- Управление с пульта ДУ Android TV

## Архитектура

- **AirPlayServer** — встроенный HTTP-сервер (NanoHTTPD) на порту 7000, обрабатывает команды AirPlay (`/play`, `/stop`, `/rate`, `/scrub`, `/playback-info`)
- **AirPlayMdnsService** — регистрирует устройство в сети через mDNS (Bonjour), чтобы Apple-устройства видели его как AirPlay-приёмник
- **AirPlayService** — фоновая служба Android (foreground service), координирует работу сервера и mDNS
- **PlayerActivity** — полноэкранный видеоплеер на ExoPlayer
- **BootReceiver** — автозапуск службы при загрузке устройства

## Инструкция по установке на Android TV приставку

### Что понадобится

1. Компьютер (Windows, macOS или Linux)
2. Android TV приставка (Xiaomi Mi Box, NVIDIA Shield, любая другая на Android TV / Google TV)
3. USB-кабель для подключения приставки к компьютеру **ИЛИ** оба устройства в одной Wi-Fi сети (для ADB по сети)

### Способ 1: Установка через ADB (рекомендуется)

#### Шаг 1. Включите режим разработчика на приставке

1. Откройте **Настройки** → **Об устройстве** (или **Система** → **Об устройстве**)
2. Найдите пункт **Номер сборки** (Build number)
3. Нажмите на него **7 раз подряд** — появится сообщение «Вы стали разработчиком»
4. Вернитесь в **Настройки** → **Для разработчиков** (Developer options)
5. Включите **Отладка по USB** (USB debugging)
6. Если хотите подключаться по Wi-Fi: включите также **Отладка по сети** (Network debugging) — запомните отображённый IP-адрес и порт

#### Шаг 2. Установите ADB на компьютер

**Windows:**
1. Скачайте [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)
2. Распакуйте ZIP-архив в удобную папку (например, `C:\adb`)
3. Откройте командную строку (Win+R → `cmd`)
4. Перейдите в папку: `cd C:\adb`

**macOS:**
```bash
brew install android-platform-tools
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt install adb
```

#### Шаг 3. Подключитесь к приставке

**По USB:**
```bash
adb devices
```
Подтвердите подключение на экране ТВ, если появится запрос.

**По Wi-Fi:**
```bash
adb connect IP_ПРИСТАВКИ:5555
```
Например: `adb connect 192.168.1.100:5555`

Проверьте подключение:
```bash
adb devices
```
Должно отобразиться ваше устройство в списке.

#### Шаг 4. Соберите APK

1. Откройте проект в Android Studio
2. Выберите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
3. APK появится в `app/build/outputs/apk/debug/app-debug.apk`

Или соберите из командной строки:
```bash
./gradlew assembleDebug
```

#### Шаг 5. Установите APK

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

Если приложение уже установлено и вы обновляете:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

#### Шаг 6. Запустите приложение

Приложение появится в списке приложений на Android TV. Запустите его с помощью пульта ДУ.

Или запустите через ADB:
```bash
adb shell am start -n com.airplay.receiver/.ui.MainActivity
```

### Способ 2: Установка через файловый менеджер

1. Соберите APK (Шаг 4 из Способа 1)
2. Скопируйте APK на USB-флешку
3. Вставьте флешку в приставку
4. На приставке установите файловый менеджер (например, **File Commander** или **X-plore**) из Google Play
5. В настройках приставки: **Безопасность** → разрешите **Установку из неизвестных источников** для файлового менеджера
6. Откройте файловый менеджер, найдите APK на флешке и установите

---

### Способ 3: Установка через Downloader (без компьютера)

1. Установите приложение **Downloader by AFTVnews** из Google Play на приставку
2. Разрешите **Установку из неизвестных источников** для Downloader
3. Загрузите APK на любой файлообменник (Google Drive, Dropbox и т.д.)
4. В Downloader введите прямую ссылку на APK
5. Скачайте и установите

## Использование

1. Запустите приложение на Android TV — служба AirPlay запустится автоматически
2. Убедитесь, что приставка и устройство Apple находятся **в одной Wi-Fi сети**
3. На iPhone/iPad/Mac:
   - Откройте видео (Safari, YouTube, и т.д.)
   - Нажмите значок **AirPlay** (прямоугольник с треугольником)
   - Выберите ваш Android TV из списка устройств
4. Видео начнёт воспроизводиться на ТВ

### Управление с пульта ДУ

- **Play/Pause** — воспроизведение/пауза
- **Back** — остановить видео и вернуться
- Также можно управлять воспроизведением с устройства Apple

### Настройки

- **Запуск при включении** — если включено, служба AirPlay запустится автоматически при загрузке приставки
- Кнопка **Запустить/Остановить** — ручное управление службой

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Устройство Apple не видит ТВ | Убедитесь, что оба устройства в одной Wi-Fi сети. Перезапустите приложение |
| Видео не воспроизводится | Некоторые DRM-защищённые потоки могут не работать. Попробуйте другое видео |
| Приложение не устанавливается | Проверьте, что разрешена установка из неизвестных источников |
| ADB не видит устройство | Проверьте, что USB-отладка включена. Попробуйте другой USB-кабель |

## Требования

- Android TV / Google TV с Android 5.0 (API 21) или выше
- Wi-Fi подключение
